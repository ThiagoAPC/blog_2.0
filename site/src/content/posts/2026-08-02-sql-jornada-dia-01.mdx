## 1. Instalação e o Primeiro Desconforto

Sinceramente, achei o processo de instalação um pouco confuso por nunca ter feito isso do zero na minha máquina local. Fui seguindo alguns tutoriais e tentando ajustar na mão.

* **Download do SQL Server:** Baixei através do [link oficial da Microsoft](https://www.microsoft.com/pt-br/sql-server/sql-server-downloads) para que o serviço rode em segundo plano na máquina.
* **Interface Gráfica:** A própria instalação do SQL Server oferece o link para baixar a interface visual logo ao finalizar.

> **Ponto de atenção:** Tive que instalar o *Visual Studio Installer* no meio do processo apenas para poder utilizar as ferramentas do SQL... Mais uma tralha ocupando espaço e bagunçando o PC, mas faz parte do jogo.

## 2. O Primeiro Contratempo: Erro de Conexão

Assim que abri a tela de conexão da interface visual pela primeira vez, me deparei com o prompt solicitando os dados do servidor:

![Tela de conexão do SQL Server](/blog_2.0/images/sql_day_1/login_sql.png)

Como de primeira a gente nunca sabe direito o que preencher, pesquisei brevemente e vi que a solução para um ambiente de dev local é simples:

1. No campo **Server Name**, digite `localhost` (ou apenas um ponto `.`).
2. Marque a caixinha **Trust Server Certificate** (*Certificado de Servidor de Confiança*).

Isso avisa ao aplicativo que ele pode confiar na conexão local do próprio computador, liberando o acesso imediato sem firulas.

> **Nota:** Com certeza vale a pena aprofundar nos aspectos de segurança e controle de acessos mais pra frente (até pelo contexto corporativo), mas no momento o foco total é meter a mão na massa em queries e manipulação de dados.

## 3. Carregando o Dataset: AdventureWorks

Com a interface conectada e funcionando, o passo seguinte foi arrumar um bom conjunto de dados para treinar consultas de todos os tipos. Escolhi o **AdventureWorks2022**, um dataset clássico da Microsoft, ideal para aprender:
* Relacionamentos entre tabelas.
* Consultas focadas em vendas e e-commerce.
* Estrutura de dados de funcionários e RH.

### Passo a passo para a restauração:

1. Baixei o arquivo `.bak` diretamente do [repositório/link oficial da Microsoft](https://learn.microsoft.com/en-us/sql/samples/adventureworks-install-configure).
2. Salvei na minha pasta centralizada de estudos de SQL.
3. No SQL Server, cliquei com o botão direito em **Databases** ➔ **Restore Database...**
4. Alterei a origem para **Device**, selecionei o caminho do arquivo `.bak` no disco e ordenei a restauração.
